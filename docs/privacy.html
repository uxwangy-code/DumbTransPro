隐私政策

最后更新：2026 年 6 月 11 日

简版：瞎翻 Pro 没有服务器、没有账号、没有统计、没有埋点。你的文字直接从你的 Mac 发给你配置的 AI 服务商，我们永远看不到。离线模式下，文字根本不出你的设备。

App 存什么、存在哪

  • 你输入的 API key 存在你设备的 macOS 钥匙串里，只发给对应的 AI 服务商端点，绝不发给我们。
  • License key 存在你设备的 macOS 钥匙串里。
  • 设置项（所选服务商、快捷键、翻译风格、免费版每日用量计数）存在本地 macOS user defaults 里。
  • 你的译文，App 根本不存储。

App 会发起的网络连接

  • 离线翻译（macOS 15+、无 key）完全在你的设备上完成，不发起任何网络请求。
  • 翻译请求（使用 AI key 时）直接从你的 Mac 发给你选的 AI 服务商（如 api.openai.com），用你自己的 key 鉴权，遵循该服务商的隐私政策。
  • 授权校验在你激活时（及之后定期）把你的 license key（仅此而已）发给 Gumroad 的授权 API。
  • 检查更新通过 Sparkle 框架从 GitHub Pages 拉取标准 appcast 文件，只涉及普通 HTTP 请求元数据（如你的 IP，GitHub 可见），不含 App 的任何个人数据。

我们收集什么

什么都不收。App 没有统计 SDK、没有崩溃上报、没有追踪。如果你发邮件找我们支持，我们会看到你的邮箱和你愿意告诉我们的内容，仅用于帮你解决问题。

购买

购买 license 时，结账由 Gumroad 和/或 Paddle 运营，他们按各自的隐私政策处理你的支付信息和邮箱；我们会收到你的邮箱和授权状态，以便提供支持。

未成年人

本 App 不面向 13 岁以下儿童，我们也不会有意收集他们的数据（我们不收集任何人的数据）。

变更

若本政策有实质性变更，新版本会连同更新日期发布于此。
