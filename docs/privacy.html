隐私政策

最后更新：2026 年 10 月 5 日 · 适用于 v1.5.5 起

简版：翻译无需注册账号。新版使用统计由你选择开启，包含随机安装编号，用于了解使用频率和稳定性；不包含翻译内容、剪贴板或密钥。你可以随时关闭，翻译和 Pro 权益不受影响。

本机存储

API Key 和 License Key 保存在本机 macOS 钥匙串。服务商、快捷键、翻译风格、统计选择和免费额度保存在本地设置中。翻译时，原文和译文在内存中用于显示及安全替换，不写入统计记录。

允许统计后，App 在 Application Support 生成随机安装编号，并保存有限重试队列。编号不来自硬件、系统账号或 License；升级后保持不变，并设置为不参与常规备份。删除应用数据会产生新编号，手动克隆数据可能复制同一编号，因此安装数不等于精确人数。

网络连接

macOS 15+ 的离线翻译在本机处理文字；首次使用可能需要联网下载 Apple 语言包。检查更新、授权校验和你允许的使用统计仍可分别联网。AI 翻译将文字和你的 API Key 直接发给你选择的服务商，遵循其政策。

授权校验向我们的授权服务或 Gumroad 发送 License Key 和校验所需的商品、应用及激活参数。更新检查通过 Sparkle 访问 GitHub Pages。使用统计发往 telemetry.whimsycode.com，由 Cloudflare Worker 和 D1 承载。普通 HTTPS 连接会向服务提供方暴露 IP 等请求元数据；我们不将 IP 存为产品统计字段，平台日志与备份由承载服务管理。

使用统计包含什么

随机安装编号、事件编号和单次操作编号；事件时间；App 与 macOS 版本；启动、开启统计、翻译开始、成功、失败、拦截或取消；原地互转或划词；AI 或离线、服务商类别、方向、风格、Free/Pro 状态；耗时区间、粗粒度错误、交付方式和队列丢弃计数。它们用于统计独立安装的使用次数和回访、排查可靠性问题，不与订单或账号关联。

统计不包含原文、译文、剪贴板内容、用户输入、API Key、License Key、自定义 Endpoint、模型名、硬件标识、姓名、邮箱或系统账号。随机安装编号可持续关联同一安装的事件，不能称为完全匿名数据。

保留与重试

本地队列最多保留 1,000 条、2 MiB 或 7 天，达到任一上限会清理。临时网络故障会重试；过期、超限、损坏或被永久拒绝的事件会丢弃并计入诊断。服务器原始使用事件按收到时间保留 90 天；安装汇总记录在连续 180 天未收到有效产品事件后清理。自动清理每小时执行，实际删除在下次成功清理时完成。

你的选择与删除记录

首次使用新版或升级后，会展示一次统计选择。在选择允许之前，不生成安装编号，不采集待补传历史。旧版已明确关闭的选择会保留；旧版默认开启不视为同意新增安装级统计。v1.5.4 及更早版本仍使用当时的无安装编号事件协议。

在「设置 → 反馈与关于 → 使用统计」随时关闭，会停止后续采集并清空待发送队列。已被服务器接收的请求可能完成，历史记录不会因关闭自动删除。本机编号会保留，便于请求删除；重新开启继续使用该编号。

可在同一设置页复制本机统计编号并点击「申请删除统计记录」，或发邮件到 hi@whimsycode.com。我们核对后删除该编号对应的事件及安装记录。邮件由你确认发送；只用于处理请求和支持。

购买

购买 license 时，结账可能由我们自己的购买页、Gumroad 和/或千寻等国内虚拟卡/支付服务提供。支付伙伴会按各自的隐私政策处理你的支付信息；我们会收到你的邮箱、订单状态和授权状态，以便提供支持。

未成年人

本 App 不面向 13 岁以下儿童，我们也不会有意收集他们的个人数据。

变更

若本政策有实质性变更，新版本会连同更新日期发布于此。
