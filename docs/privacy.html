隐私政策

最后更新：2026 年 6 月 28 日

简版：瞎翻 Pro 没有账号，也不收集你的翻译原文、译文、API Key、License Key、剪贴板内容、输入内容或个人身份信息。匿名使用数据默认开启，用于帮助我们改进服务；你可以随时在设置里关闭。

App 存什么、存在哪

  • 你输入的 API key 存在你设备的 macOS 钥匙串里，只发给对应的 AI 服务商端点，绝不发给我们。
  • License key 存在你设备的 macOS 钥匙串里。
  • 设置项（所选服务商、快捷键、翻译风格、匿名使用数据偏好、免费版每日用量计数）存在本地 macOS user defaults 里。
  • 你的译文，App 根本不存储。

App 会发起的网络连接

  • 离线翻译（macOS 15+、无 key）完全在你的设备上完成，不发起任何网络请求。
  • 翻译请求（使用 AI key 时）直接从你的 Mac 发给你选的 AI 服务商（如 api.openai.com），用你自己的 key 鉴权，遵循该服务商的隐私政策。
  • 授权校验在你激活时（及之后定期）把你的 license key（仅此而已）发给我们的授权服务或 Gumroad 的授权 API。
  • 检查更新通过 Sparkle 框架从 GitHub Pages 拉取标准 appcast 文件，只涉及普通 HTTP 请求元数据（如你的 IP，GitHub 可见），不含 App 的任何个人数据。
  • 匿名使用数据默认开启，可在「设置 → 反馈与关于」关闭。它使用普通 HTTPS 请求，因此接收端可能看到标准请求元数据，例如你的 IP 地址。

我们收集什么

匿名使用数据用于帮助我们改进服务。App 可能发送这些产品层面的事件：启动、翻译成功或失败、使用路径（原地互转或划词翻译）、provider 类型、AI/离线路由、粗粒度错误类型、App 版本、macOS 版本、Free/Pro 状态。

匿名使用数据绝不会发送翻译原文、译文、API Key、License Key、剪贴板内容、输入内容、自定义 endpoint URL、模型名称、持久设备 ID、姓名、邮箱或其他直接个人身份标识。发送失败会静默丢弃，不写入本地重试队列。

如果你发邮件找我们支持，我们会看到你的邮箱和你愿意告诉我们的内容，仅用于帮你解决问题。

购买

购买 license 时，结账可能由我们自己的购买页、Gumroad 和/或面包多 Pay 等国内支付服务提供。支付伙伴会按各自的隐私政策处理你的支付信息；我们会收到你的邮箱、订单状态和授权状态，以便提供支持。

未成年人

本 App 不面向 13 岁以下儿童，我们也不会有意收集他们的个人数据。

变更

若本政策有实质性变更，新版本会连同更新日期发布于此。
