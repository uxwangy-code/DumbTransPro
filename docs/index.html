常见问题

我没有 API key，有影响吗？

macOS 15+ 完全没影响。装上就能离线翻，给你正翻和 kebab 文件名，不用 key、不用账号、也不联网。想玩土翻/装翻，或者你在 macOS 13/14，填个免费的智谱 key（glm-4-flash）粘一下就行。

我的文字隐私吗？

离线时（macOS 15+、无 key），翻译全程在设备端，文字根本不出你的 Mac。配了 key，则直连你配置的 AI 服务商。无论哪种，app 都没有服务器、不收集任何东西；唯一的联网是授权校验（Gumroad）和检查更新。详见隐私政策。

一份授权能用几台 Mac？

你自己的 Mac 都行，工作本、家里的机器都没问题。授权按人算，不按设备。

要是不合适呢？

14 天内邮件联系我们，全额退款，不问理由。见退款政策。

为什么叫「瞎翻」？

因为土翻模式会把「加油」翻成 add-oil，而我们拒绝为此道歉。
